# EDP Internship - Week 3

## Topic
Spam Classification

## Objective
To build a basic spam classifier using text processing and machine learning.

## Tools Used
- Python
- Pandas
- Scikit-learn

## Work Completed
- Loaded and prepared a spam and ham message dataset.
- Converted text into numerical features using TF-IDF.
- Trained a Naive Bayes classification model.
- Evaluated the model using accuracy, precision, recall, and F1-score.
- Tested the model with new messages.

## Result
The model achieved 75% accuracy on the test data.

## Files
- `spam_messages.csv` - Dataset
- `spam_classifier.py` - Spam classification implementation
