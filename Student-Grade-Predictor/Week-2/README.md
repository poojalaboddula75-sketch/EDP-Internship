# EDP Internship - Week 2

## Topic
Linear Regression

## Objective
To build a Linear Regression model for predicting student marks based on study hours.

## Tools Used
- Python
- Pandas
- Scikit-learn

## Work Completed
- Loaded a student performance dataset.
- Identified StudyHours as the feature and Marks as the target.
- Split the data into training and testing sets.
- Trained a Linear Regression model.
- Predicted student marks.
- Evaluated the model using MAE, MSE, and R2 Score.

## Result
Successfully trained and evaluated a Linear Regression model for predicting student marks from study hours.

- `student_performance.csv` - Dataset
