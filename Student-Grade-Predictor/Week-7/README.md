# EDP Internship - Week 7

## Project
Student Grade Predictor

## Topic
Prediction Error Analysis and Visualization

## Objective
To analyze the difference between actual and predicted student marks and visualize model prediction performance.

## Work Completed

- Loaded prediction results using Pandas.
- Calculated prediction error.
- Calculated absolute error.
- Calculated Mean Absolute Error (MAE).
- Identified the maximum prediction error.
- Created a Predicted vs Actual visualization.
- Saved the visualization as an image.

## Dataset Columns

- ActualMarks
- PredictedMarks
- Error
- AbsoluteError

## Evaluation

The prediction errors were calculated by comparing actual marks with predicted marks.

The Mean Absolute Error was approximately 0.96 marks.

## Visualization

The Predicted vs Actual graph was created to understand how closely the predicted marks match the actual marks.

## Tools Used

- Python
- Pandas
- Matplotlib
